# الموقع العام لسبورت باور — www.sport-power.net

مشروع مستقل عن النظام الداخلي في المستودع نفسه: صفحات ثابتة بالعربية
(`/`) والإنجليزية (`/en/`) تُبنى بسكربت بلا اعتماديات، وصفحة الدورة
تُولَّد عند الطلب من بيانات النظام. كل ما يُعدَّل في النظام (الباقات،
الفروع، الدورات، بيانات التواصل) يظهر على الموقع خلال دقائق بلا نشر جديد.

```
site/
├── build.js            البناء إلى dist/  (node build.js) والمعاينة (node build.js --serve)
├── lib/render.js       محرّك القوالب الصغير + اللغتان (مشترك بين البناء وصفحة الدورة)
├── lib/config.js       عناوين النظام والموقع من متغيرات البيئة
├── api/course.js       /courses/:slug — تُولَّد من واجهة النظام عند الطلب (Vercel Function)
├── src/layout.html     الهيكل المشترك (الترويسة والتذييل)
├── src/pages/*.html    الصفحات: الرئيسية، الباقات، الدورات، الدورة، الانضمام، المتجر، من نحن، الخصوصية، شكرًا، 404
├── src/i18n/ar.json    النصوص العربية   ← عدّل النصوص هنا
├── src/i18n/en.json    النصوص الإنجليزية (المفاتيح نفسها — الاختبار يتحقق)
├── src/data/shop.json  منتجات المتجر الأربعة
├── public/             CSS وJS والخطوط والشعارات — تُنسخ كما هي
└── vercel.json         إعدادات مشروع Vercel الخاص بالموقع
```

## ما يأتي من النظام (لا يُحرَّر هنا)

| على الموقع | يُدار من النظام في |
|---|---|
| الباقات وأسعارها وعملة كل فرع | الباقات والعقود |
| الفروع وعناوينها وهواتفها | الإعدادات → الفروع |
| الدورات (المحاور والباقات، عربي/إنجليزي) | الدورات والموقع |
| الهاتف وواتساب والبريد والحسابات | الإعدادات → الموقع الإلكتروني |
| نماذج الانضمام والاهتمام بالدورات | تصل «متابعة المبيعات» بقناة «الموقع الإلكتروني» مع إشعار |

واجهة النظام المستعملة: `GET /api/public/site` و`GET /api/public/site/courses/:slug`
و`POST /api/public/site/leads` — عامة بلا مصادقة، محدودة المعدّل، وCORS مقصور
على أصل الموقع (`SITE_ORIGINS` في مشروع النظام).

## النشر على Vercel (مشروع ثانٍ من المستودع نفسه)

1. **New Project** من المستودع `markerstudio/sportpower` → **Root Directory: `site`**.
   Framework Preset: Other. (أمر البناء ومجلد الإخراج مضبوطان في `vercel.json`.)
2. Environment Variables:

   | المتغير | القيمة |
   |---|---|
   | `SITE_API_BASE` | عنوان النظام، مثل `https://app.sport-power.net` |
   | `SITE_APP_URL` | (اختياري) عنوان تسجيل الدخول إن اختلف — افتراضيًا = `SITE_API_BASE` |
   | `SITE_URL` | `https://www.sport-power.net` |

3. في **مشروع النظام** (لا الموقع) أضف `SITE_ORIGINS` بأصول الموقع:
   `https://www.sport-power.net,https://sport-power.net,https://*.vercel.app`
   (النمط الأخير لنسخ المعاينة — أزله بعد الإطلاق إن شئت.)
4. افتح رابط المعاينة وتحقق: الباقات والفروع تظهر، نموذج الانضمام يصل
   إلى متابعة المبيعات، وصفحة `/courses/coach-business` تعمل بالعربية والإنجليزية.

## نقل النطاق من Wix

النطاق `sport-power.net` مسجَّل عند Wix. الترتيب الآمن:

1. **قبل أي شيء**: انسخ من Wix ما تريد الاحتفاظ به — صور المنتجات الأربعة
   (ضعها في `public/images/shop/` وحدّث الروابط في `src/data/shop.json`)،
   وأي صور أو نصوص أخرى. صفحات «challenge-page» (16 صفحة خاصة بأسماء
   متدربين من 2023–2024) ستختفي مع Wix؛ إن أردت شيئًا منها فصدّره الآن.
2. في Vercel → مشروع الموقع → **Domains**: أضف `www.sport-power.net`
   و`sport-power.net` (يعرض لك سجلات DNS المطلوبة).
   وفي مشروع النظام أضف `app.sport-power.net`.
3. في Wix → **Domains → Advanced → DNS**: أضف السجلات كما طلبها Vercel
   (`A` للجذر إلى عنوان Vercel، و`CNAME` لـ`www` و`app` إلى
   `cname.vercel-dns.com`). احذف سجلات Wix القديمة للجذر و`www`.
   تحقق في Vercel حتى تصير الحالة **Valid Configuration**.
4. اترك Wix أسبوعًا كنسخة احتياطية ثم ألغِ خطة Premium (لا النطاق).
   لاحقًا يمكنك نقل تسجيل النطاق نفسه من Wix إلى مسجِّل آخر
   (Transfer) — غير ضروري للتشغيل.
5. الروابط القديمة (`/plans-pricing`, `/blank-4`, `/challenge-page/*`,
   `/book-online`) تُحوَّل تلقائيًا (انظر `redirects` في `vercel.json`).

## التطوير محليًا

```bash
# الطرف الأول: النظام
npm start                               # http://localhost:3000
# الطرف الثاني: الموقع
cd site && SITE_API_BASE=http://localhost:3000 node build.js --serve   # http://localhost:4000
cd site && npm test                     # اختبارات البناء والقوالب
```

محليًا يُسمح لأصل `localhost` بمخاطبة النظام تلقائيًا (بلا `SITE_ORIGINS`).

## تعديلات شائعة

- **نص في صفحة**: `src/i18n/ar.json` و`src/i18n/en.json` (المفتاح نفسه في الملفين).
- **صفحة جديدة**: أضف `src/pages/<name>.html` وسطرًا في `src/pages.json`
  ومفاتيح `title_<name>` و`desc_<name>` في ملفي اللغة.
- **منتج في المتجر**: `src/data/shop.json`.
- **صورة المشاركة** (Open Graph): ضع `public/images/og.png` بقياس 1200×630.
