# نظام سبورت باور الداخلي — SportPower Internal System

نظام إدارة داخلي كامل بالعربية (RTL) لشركة **سبورت باور**، مبني وفق البريف الرسمي
وبهوية SportPower البصرية (مشروع SportPower Design System في Claude Design).

## التشغيل محليًا (وضع العرض)

```bash
npm install
npm start          # http://localhost:3000
npm run seed       # إعادة تهيئة البيانات التجريبية
```

بلا إعداد: يخزّن في `data/db.json` مع بيانات تجريبية كاملة (وضع العرض).

## النشر للإنتاج (الطريقة الآمنة والموثوقة) ✅

التخزين الدائم عبر **Postgres مُدار** — عند ضبط `DATABASE_URL` ينتقل النظام
تلقائيًا إلى Postgres: بيانات دائمة، نسخ احتياطي من المزود، وخصم الحصص
داخل معاملة ذرّية (Transaction) بقفل صف الاشتراك.

### على Vercel (المشروع الحالي)

1. أنشئ قاعدة Postgres مجانية من تبويب **Storage** في مشروع Vercel
   (Neon) أو من [neon.tech](https://neon.tech) / [supabase.com](https://supabase.com).
2. في إعدادات المشروع → **Environment Variables** أضف:
   - `DATABASE_URL` — رابط الاتصال (Connection string) من المزود.
     (تكامل Vercel Postgres يضيف `POSTGRES_URL` تلقائيًا — مدعوم أيضًا.)
   - `ADMIN_PASSWORD` — كلمة مرور قوية لحساب `admin` (إن لم تُضبط، يبدأ
     الحساب بكلمة `admin123` مع تحذير إلزامي بتغييرها من داخل النظام).
3. أعد النشر (Redeploy). تحقق من `/api/health` → `{"ok":true,"storage":"postgres"}`.

عند أول تشغيل على قاعدة فارغة يُزرع الحد الأدنى فقط: حساب المدير + الفروع +
مكتبة الوجبات — بلا حسابات تجريبية ولا تظهر بياناتها في شاشة الدخول.
لبيئة عرض على Postgres أضف `SEED_DEMO=1`.

### الأمان المطبق

- كلمات المرور: **scrypt** بملح لكل مستخدم (وليس تجزئة بسيطة).
- الجلسات: رموز عشوائية 256-bit تُخزن **مجزأة** وتنتهي بعد 12 ساعة (تمديد تلقائي).
- تغيير كلمة المرور يُنهي بقية جلسات المستخدم. زر 🔑 في الشريط العلوي.
- حد لمحاولات الدخول: 8 لكل مستخدم / 30 لكل IP كل 15 دقيقة.
- ترويسات أمان: CSP، `X-Frame-Options: DENY`، `nosniff`، وHTTPS مفروض من Vercel.
- الصلاحيات مفروضة في الخادم لكل مسار (وليس في الواجهة فقط).

## أنواع المستخدمين والصلاحيات

- **الإدارة** — ترى كل الفروع والمدربين والمتدربين. داش بورد شامل: حصص يومي/شهري،
  عدد الأشخاص وساعات التدريب لكل مدرب، المتدربون الفعالون، الاشتراكات المنتهية
  والقريبة من الانتهاء، الدفعات والتحصيلات، قراءات InBody. تعدّل البرامج والمواعيد والحصص.
- **المدرب** — حساب خاص، جدول حصصه اليومي على Calendar، تنبيه قبل الحصة، والمدربون يتناوبون على المتدربين (الحصة تُنسب لمن نفّذها)،
  تعديل المواعيد، وتسجيل الحصة (المتدرب/التاريخ/الساعة/المدة/الأسلوب/الملاحظات/الوزن).
- **المحاسب** — إدخال المشترك الجديد (Onboarding) والتجديد والتجميد/الإلغاء بسبب مسجَّل،
  البيانات المالية: قيمة الاشتراك/المدفوع/المتبقي/تاريخ وطريقة الدفع، المجددة والمنتهية،
  إضافة وتعديل الدفعات، تسجيل **المصاريف الشهرية** ورؤية **صافي الربح**، متابعة المبيعات (Leads)،
  بروفايل كل متدرب (بياناته واشتراكاته ومدفوعاته)، والأهداف الشهرية/السنوية بوضوح مع الترحيل.
- **المتدرب** — رصيد الحصص (الكلي/المستخدم/المتبقي)، جدول مواعيده، قراءات الوزن
  والـ InBody مع مقارنة، ملاحظات المدرب، تاريخ الاشتراك والانتهاء، برنامجه الغذائي والتدريبي،
  وقسم **«نقاطي ومكافآتي»**: نقاط الولاء وسجلها والمكافآت وكود «ادعُ صديقًا».

## نظام الحصص (منطق الاحتساب)

عند حفظ حصة من المدرب:
1. تُحفظ الحصة باسم المتدرب وتُخصم حصة من رصيده ويظهر له «متبقي 11 من أصل 12».
2. تُضاف لأداء المدرب الشهري (عدد الحصص + عدد الأشخاص).
3. تُسجل الساعة التدريبية: **شخصان بنفس الساعة = ساعة تدريب واحدة، وعدد الأشخاص = 2**
   (الساعات تُحسب بالساعات المميزة: مدرب + تاريخ + ساعة بدء).
4. الأرقام تتحدث تلقائيًا في كل اللوحات.

## الميزات

- **Calendar مشترك** أسبوعي: الإدارة تضيف مواعيد وترى جدول كل المدربين معًا مع فلتر،
  المدرب يرى مواعيده ويعدلها، وتصل إشعارات عند الإضافة أو التعديل.
- **InBody Reader**: رفع صورة القراءة، محاولة قراءة تلقائية OCR (عبر tesseract.js إن توفر —
  مع نموذج يدوي دائمًا)، حفظ كل القراءات حسب التاريخ، ومقارنة (الوزن/الدهون/العضلات/الماء/BMI).
- **الإشعارات**: مواعيد جديدة أو معدلة، تنبيه قبل الحصة، اشتراكات قريبة من الانتهاء، خصم الحصص.
- **التقارير الشهرية** لكل مدرب وفرع + تصدير **Excel (CSV)** و**PDF (طباعة)** — وتشمل
  **تقرير النمو** وفق مؤشرات الشركة: المشتركون الجدد، المجددون ونسبة التجديد (Retention)،
  الإلغاءات ونسبتها وأسبابها، المجمدون ونسبتهم، النمو الصافي (Net Growth)، النشطون،
  متوسط بقاء العميل، قيمة العميل (LTV)، والمقارنة بالهدف الشهري والسنوي.
- **المصاريف الشهرية وصافي الربح**: المحاسب يسجل مصاريف كل شهر (رواتب/إيجار/تسويق…)
  وتظهر في التقرير الشهري مع التحصيل وصافي الربح.
- **الأهداف مع الترحيل التلقائي**: الهدف الشهري لكل فرع ظاهر بوضوح، الهدف السنوي مقسم
  على أشهر السنة، وما لم يتحقق من هدف شهر منقضٍ يُرحَّل تلقائيًا لهدف الشهر التالي.
- **متابعة المبيعات (Leads)**: ملف بكل رقم تم التواصل معه (القناة، السكن، الهدف، المرحلة،
  الاعتراض)، وتحليل شهري: نسبة الإغلاق، أين مشاكل المبيعات (غالي/بعيد/لم يحضر التجربة…)،
  وتحويل العميل المحتمل لمشترك بضغطة واحدة.
- **نظام الولاء «نقاطي ومكافآتي»**: نقاط عند حضور الحصص وتجديد الاشتراك وتحقيق الأهداف
  (منح يدوي من الإدارة)، مكافآت قابلة للاستبدال (خصم/بلوزة/حصة إضافية/شهر مجاني)
  باعتماد الإدارة، وتحكم كامل بقيم النقاط والمكافآت.
- **الإحالات «ادعُ صديقًا»**: كود خاص لكل مشترك ومشاركة عبر واتساب (للاشتراك أو لحصة
  تجريبية)، اعتماد الإحالة من الإدارة يمنح المُحيل نقاطه، مع تقارير بالإحالات والاستبدالات.
- **الحصص التعويضية**: خيار «تعويض» في الجدول اليومي وتسجيل الحصص — تُسجل باستقلال
  عن الحصص العادية وبلا خصم من رصيد الاشتراك.
- **البرامج التدريبية**: المدرب ينشئ برنامجًا فيُربط تلقائيًا بكل المتدربين ويصلهم إشعار.
- **مكتبة التغذية**: وجبات بالسعرات والماكروز والمكونات وطريقة التحضير والنوع والهدف،
  إضافة من المدرب/الأخصائية، عرض حسب هدف المتدرب، بحث وفلترة (سعرات/بروتين/نوع/هدف)،
  وربط الوجبات ببرنامج المتدرب اليومي.
- **سهل الاستخدام على الموبايل والكمبيوتر** — واجهة متجاوبة بالكامل.
