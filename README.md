# سبورت باور — SportPower (الموقع العربي)

موقع تسويقي عربي كامل (RTL) لعلامة **سبورت باور**، مبني على
مشروع **SportPower Design System** في Claude Design — نظام هوية مشتق من
دليل الهوية البصرية الرسمي (Marker Creative Studio™) ومقترح إعادة التموضع 2026.

**الرسالة الجوهرية:** جسم أقوى. حياة أصحّ. نظام يبقى معك.

## المحتوى

| القسم | المصدر في نظام التصميم |
|---|---|
| الترويسة الثابتة (بترولي + شعار أبيض + CTA أخضر) | `ui_kits/website/Header` |
| الواجهة: عنوان ضخم + وسوم + إحصاءات + علامة ضخمة شفافة | `ui_kits/website/Hero` |
| ركائز النظام (4 بطاقات بأيقونات مونولاين) | `components/core` + المقترح |
| البرامج الثلاثة (باور بيلد / ميتكون ميكس / العقل والمرونة) | `ui_kits/website/Programs` |
| «ابدأ من حيث أنت» — خطوات النظام الثلاث | مقترح إعادة التموضع |
| «ثلاثة فروع. رسالة صحية واحدة.» | مقترح إعادة التموضع |
| آراء الأعضاء + شريط الإحصاءات على بترولي | `ui_kits/website/Feedback` |
| دعوة الانضمام بالأخضر الكامل | `ui_kits/website/JoinCTA` |
| نافذة الانضمام (تحقق + حفظ محلي + حالة نجاح) | `ui_kits/website/JoinModal` |
| التذييل (بترولي 900) | `ui_kits/website/Footer` |

## الهوية

- **الألوان:** Fuel Green `#79BE43` · Power Petrol `#153131` · Core Blue `#3772FF` · Base Grey `#E7E7E7`
- **الخط العربي:** Cairo (مطابق للهوية) — الأرقام واللاتيني: Rubik (بديل Erbaum المجاني)
- **الوضعان الفاتح والداكن** مدعومان (زر ◐ في الترويسة) وفق صفحة 25 من دليل الهوية.
- **الشعارات:** ملفات SVG رسمية في `assets/`. أيقونات البرامج الأربع
  (طاقات/ميكس/اجواء/فيدباك) أُعيد رسمها كـ SVG مونولاين بأسلوب الهوية
  (الأصول الأصلية PNG موجودة في مشروع التصميم).

## التشغيل

الموقع ثابت بلا خطوات بناء:

```bash
# أي خادم ثابت
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

طلبات الانضمام تُحفظ محليًا في `localStorage` تحت المفتاح `sp-signups`.

## البنية

```

└── assets/             الشعارات الرسمية + أيقونات البرامج
```
